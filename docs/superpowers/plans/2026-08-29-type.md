# Type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Type, a personalized typing trainer at `/type` in the UDM+ web app (not Discord).

**Architecture:** One client typer + pure engine (score, weakness, word gen, workout, daily). Server recomputes scores from a compact log, stores per-key stats and sessions, gates everything on first placement. Social layer is official daily + two boards + badges + coins via `emitOutbox`.

**Tech Stack:** Next.js 14 App Router, Prisma/Postgres, Zod, existing `apiHandler` / `requireUser` / `emitOutbox` / `COIN_RULES`. No new deps. Gate is `npm run typecheck`.

## Interfaces (locked names)

```ts
export type SessionKind = "placement" | "workout" | "daily" | "sandbox" | "targeted";
export type SessionMode = "time" | "words" | "quote";

export type RunConfig = {
  kind: SessionKind;
  mode: SessionMode;
  durationSec?: number;
  wordCount?: number;
  punctuation: boolean;
  numbers: boolean;
  targetKeys: string[];
  quoteId?: string;
  dailyDate?: string; // YYYY-MM-DD UTC
  workoutId?: string;
  pieceId?: string;
  seed: string;
};

export type Stroke = { t: number; expect: string; got: string };

export type Score = {
  wpm: number;
  rawWpm: number;
  accuracy: number;
  correctChars: number;
  incorrectChars: number;
  durationMs: number;
};

export function isRated(config: Pick<RunConfig, "kind" | "mode" | "durationSec" | "punctuation" | "numbers" | "targetKeys">): boolean;
export function scoreRun(prompt: string, log: Stroke[], durationMs: number): Score;
export function weakness(hits: number, misses: number, latencyEmaMs: number, medianMs: number): number | null;
export function pickTargets(stats: { grapheme: string; hits: number; misses: number; latencyEmaMs: number }[]): string[];
export function generateWords(opts: {
  list: string[];
  seed: string;
  n: number;
  targets?: string[];
  targetRatio?: number;
  punct?: boolean;
  numbers?: boolean;
}): string[];
export function buildWorkout(opts: { date: string; targets: string[]; quotePack: { id: string; text: string; length: "short" | "medium" }[] }): {
  date: string;
  pieces: { id: string; kind: string; config: RunConfig }[];
};
export function dailyPassage(opts: { date: string; wordList: string[]; quotePack: { id: string; text: string; length: "short" | "medium" }[] }):
  | { kind: "words"; words: string[] }
  | { kind: "quote"; quoteId: string; text: string };
export function utcDateKey(now?: Date): string;
```

`placement_required` is `HttpError(403, "placement_required")`.

### Task 1: Engine + word list + quotes

**Files:** create `engine.ts`, `words.ts`, `quotes.ts`

- [ ] Implement the interfaces above. Seeded mulberry32 PRNG. WPM = `(correctChars / 5) / minutes`. Learning threshold 8. Weak if samples ≥ 20 and weakness ≥ 0.25. Targets = top 3 qualifying `a–z`, else least-sampled letters. Target mix 60/40 (workout mixed piece uses 0.3). Daily words unless `floor(utcMidnightMs / 86400000) % 7 === 0` then a medium quote. Rated = time 60, no punct, no numbers, no targets, kind placement or sandbox.
